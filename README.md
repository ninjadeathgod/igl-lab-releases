# igl-lab-releases
Official Windows downloads for IGL Lab by IGL Systems.

## Download IGL Lab Portable

**[Download IGL Lab Portable v0.2.0 for Windows x64 (ZIP, 73.05 MB)](https://github.com/ninjadeathgod/igl-lab-releases/releases/download/v0.2.0/IGL-Lab-Portable-x64.zip)**

[Release details and checksum](https://github.com/ninjadeathgod/igl-lab-releases/releases/tag/v0.2.0)

Requires Windows 11 x64, build 22000 or later. The .NET runtime is included. This is an unsigned evaluation build.

1. Download `IGL-Lab-Portable-x64.zip` using the link above.
2. Extract the entire ZIP to a writable folder.
3. Open the extracted folder and run `IGL-Lab.exe`. Keep all bundled files together.

The ready-to-run app is the portable ZIP linked above. GitHub's green **Code > Download ZIP** option and the **Source code** release downloads contain the repository files, not the portable application.
